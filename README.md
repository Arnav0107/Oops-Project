# ⚔️ Battle Arena - C++ OOP Showcase

Please refer to the complete documentation and code in [`battle-arena/`](file:///d:/Study/OOPS%20Project/battle-arena/README.md).

## Quick Run

### 1. Engine
```bash
cd battle-arena/engine
g++ -std=c++17 -Wall -Wextra -O2 -Iinclude src/*.cpp -o battle_engine.exe
# Optional: test console fallback mode
.\battle_engine.exe --console
```

### 2. Node Server
```bash
cd battle-arena/server
npm install
npm start
```

### 3. React Client
```bash
cd battle-arena/client
npm install
npm run dev
```

See [battle-arena/README.md](file:///d:/Study/OOPS%20Project/battle-arena/README.md) for full architecture diagrams, Mermaid UML class diagram, OOP concepts mapping, and Wi-Fi multiplayer setup instructions.
